# Dodgeball Game

## About the Project
This is a dodgeball game I made using Java. The idea behind the game is pretty simple: avoid getting hit by the balls and try to survive as long as possible.

I made this project to practice my Java programming skills and get a better understanding of how different parts of a program work together.

## How It Works
The game involves moving your player around while trying to avoid incoming balls. The goal is to stay alive without getting hit.

## How to Run It
1. Download the files from this repository.
2. Make sure you have Java installed.
3. Open the code in a Java IDE.
4. Run the program and start playing.

## What I Learned
Working on this project helped me get more comfortable with Java, especially when it comes to organizing code, working with game mechanics, and troubleshooting errors.
